03 · embedding map — every token the model knows, projected to 2D

Each dot is one vocabulary token's learned embedding, reduced from 32 dimensions to 2 with PCA — no labels chosen by hand, just the geometry the model arrived at during training. Tokens currently in your input are highlighted amber; hover any dot to see which token it is.

Distance is meaningful, axes are not — PCA finds the two directions of greatest variance in the embedding space, so proximity means "the model treats these similarly," not any fixed semantic label.

04 · what you are looking at

tokenizer

Byte-pair encoding trained live: start from single characters, repeatedly merge the most frequent adjacent pair. Each chip is one token — note how common words become single tokens while rare ones split apart.

probability heat

Each token is coloured by the probability the model assigned to it before seeing it, given everything to its left. Teal = the model saw it coming. Red = surprise. This is exactly the loss an LLM is trained to minimise.

attention

Inside the model, every token builds a weighted mixture of the tokens before it. The arcs show those weights for one head. Different heads learn different habits — switch to "both" to see H1 (amber) and H2 (blue) overlaid on the same sentence at once.

embedding map

Before any attention happens, every token is just a point in 32-dimensional space. Training moves those points around so tokens that behave alike end up near each other — this panel is that space, flattened to 2D.
